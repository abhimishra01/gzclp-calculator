# Code review, lens: regression (Kim)

Verdict: FAIL for launch. The pure rules in `gzclp.js` are correct against the cited wiki, but the print feature prints a blank page, undo after a unit switch corrupts weights, and T2 reset has two defects. 4 must-fix, 5 should-fix, 4 nice.

Source checked: thefitness.wiki/routines/gzclp/ (fetched 2026-10-20). It confirms: T1 5x3+, 6x2+, 10x1+, "Test for a new 5 rep max. Use 85% of this weight to restart the cycle"; T2 3x10, 3x8, 3x6, reset "Find the last weight you lifted using Stage 1, add 15-20 lbs"; T3 3x15+, "Add weight when you can do 25 reps on your AMRAP set"; +5 lb bench and press, +10 lb squat and deadlift; day layout and rest times as coded. The source gives NO kg numbers, NO T3 jump size, NO starting weights, and no minimum for the AMRAP set beyond "complete the total number of reps".

Hand recomputed (all agree with code and the live page): (1) squat 135 pass -> 145; bench 95 pass -> 100. (2) T1 squat 135 fail, fail, fail -> 135 5x3+, 135 6x2+, 135 10x1+, then 114.75 -> 115 lb 5x3+. (3) T1 92.5 kg at 10x1+ miss -> 78.625 -> 77.5 kg. (4) T2 bench 65: miss, miss, miss -> 80 lb 3x10 (base 65 + 15). (5) T2 stage 2 pass at 100 with base 95 -> 110, base stays 95. (6) T3 lat 70: 24 reps stays 70, 25 reps -> 75. (7) 5RM 225 -> 191.25 -> 190 lb. (8) Plates: 135 lb = 45 per side; 100 lb = 25 + 2.5; 315 lb = 3 x 45; 52.5 lb with no 1.25 plate gives 2.5 per side and says closest is 50 lb. 19 of 19 tests pass.

Template rules hold: canonical points to https://gzclpcalculator.com/ on all pages (also on the Pages build); `_headers` has noindex for the pages.dev host and preview host only; footer links About, Contact, Privacy, Terms; 404 exists and is noindex; sitemap lists 5 pages without 404; robots.txt points to the sitemap; GA4 and AdSense scripts absent while empty and ads.txt is a comment. Pages build (`PAGES_BASE=/gzclp-calculator/`) has noindex, all links under the base, manifest start_url under the base. Known template leftovers: not reviewed.
